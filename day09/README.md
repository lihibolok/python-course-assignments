# Day 09 – Submission Report

This folder contains my solution for the **Day 09** assignment.

The goal is to use:

- the issues in `day09/subjects.txt`, and  
- the assignment dead-lines from the course `README.md`

to generate a report about submissions.

## Files

- `subjects.txt`  
  Issues copied from the shared course repository, one per line:

  ```text
  <issue-id> <STATUS> <subject> <timestamp>
  ```

- `report.py`  
  Reads `subjects.txt`, uses hard-coded dead-lines (taken from the README), and creates a text report.

- `report.txt`  
  The report generated by `report.py`.

## What the script reports

For each assignment (e.g. `Day01`, `Day02`, …, `Day09`, `Project proposal`, `Project submission`), the script:

- Counts how many issues there are, and how many are `OPEN` vs `CLOSED`.
- Classifies submissions as **on time** or **late** (when a dead-line is known).
- Lists up to 30 late submissions, including:
  - issue ID,
  - assignment,
  - student name,
  - submission time,
  - and how many days late it was.

## How to run

From the root of the `python-course-assignments` repository:

```bash
python day09/report.py
# or
python3 day09/report.py
```

The report is printed to the terminal and saved as `day09/report.txt`.
